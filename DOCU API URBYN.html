Configuration URL API (front)

Au démarrage du front, un seul test GET /health est fait (pas à chaque appel).

VariableRôle
VITE_API_URL_WEB URL Render (prioritaire). Ex. https://crm-urbanize.onrender.com
VITE_API_URL_LOCAL Fallback si le web ne répond pas. Défaut : http://127.0.0.1:8000

Ordre : WEB → LOCAL. Si aucune ne répond, écran d'erreur avec bouton « Réessayer ».

const API = 'https://votre-service.onrender.com';

const res = await fetch(`${API}/api/v1/auth/login`, {
  method: 'POST',
  headers: { 'Content-Type': 'application/json' },
  body: JSON.stringify({
    email: 'user@example.com',
    password: '********',
    account_type: 'partner',
  }),
});
const user = await res.json();
